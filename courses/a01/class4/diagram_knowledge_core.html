系統功能流轉細節

📥

1. 多元輸入管道

企業每日有大量重要資訊流動。本層級打破資訊孤島，無論是公務/私人 Email 郵件附件、LINE 官方帳號對話，或是 Telegram Bot 的即時指令與圖片檔案，皆視為核心數據源。

Email IMAP LINE Webhook Telegram Bot
⚙️

2. ETL 整理與轉換

非結構化資訊的洗滌區。資料經過「攝取」、「清理」、「解析（利用 OCR 解析文件與圖片文字）」以及關鍵資訊的「標註」，最終「載入」AI 知識庫，將雜亂資訊洗滌為結構化黃金資料。

LlamaParse FALO OCR LLM Metadata
🗄️

3. AI 統一知識核心 (KM)

企業的中央大腦。統一儲存並建立「文件檔案」、「對話紀錄」與「事件任務」的關聯與記憶。利用向量化儲存支援超高性能語意檢索，實現跨項目人、事、時、地的智能網狀連結。

Vector DB Graph Memory Hybrid Search
🤖

4. AI Agent 智慧運用

頂層邏輯處理單元。AI Agent 讀取統一知識庫後，可靈活執行智慧 Q&A、進度自動追蹤任務、分析洞察預測、產生文件或簡報，並在特定閾值觸發時主動進行提醒與安全預警。

LangGraph Task Scheduler Proactive Agent

四層技術架構說明

🖥️

前端 (入口層)

預設採用 Google Apps Script (GAS) 或 Cloudflare。負責做為流量的第一道防線，執行身分驗證與權限控管，提供簡單的 Portal 表單輸入，並執行最初步的驗證與分流，將任務派送至後端處理。

Apps Script Cloudflare Pages API Gateway
⚡

中間 (處理層)

預設採用 Google Cloud Run。做為 FALO AI 的核心運算引擎與 Runtime 執行環境。利用 Python 連接 OpenAI / Gemini 模型，部署複雜的非同步 ETL 洗滌程序、OCR 影像解析、影片摘要以及 Agent 自主排程任務。

GCP Cloud Run Python App Docker Container
💾

後端 (資料層)

預設為 Google 生態系 (Workspace)。資料完全儲存在客戶自有的雲端空間，包含 Google Drive 專屬資料夾、Sheets 表格庫（充當關聯資料庫）、Docs 文件協作、Gmail 郵件派送，並使用 NotebookLM 作為隨插即用的知識庫。

Google Sheets Shared Drive NotebookLM
🔌

輔助 (彈性節點)

PC AI Node (地端代理程式)。此為非預設的彈性路徑，僅在有內網安全存取、地端硬體運算（如 Ollama 本地模型跑敏感 OCR）或需要操作地端 Office / Outlook 自動化等特殊情況下，由 Cloud Run 透過安全 VPN 隧道觸發啟用。

Ollama Local Tailscale VPN Office Automation

一個入口，多種來源；一個核心，智慧整合；一個 Agent，創造最大價值！

這套架構實現了「萬佛朝宗」的終極目的：將企業日常四散的零碎流程與文檔完全整合。透過前端 GAS/Cloudflare 控管權限、中間 Cloud Run 進行智能洗滌與 Agent 執行、後端 Google Sheets/Docs 儲存協作，實現資料安全、權限分明且靈活可控的 AI 落地。
